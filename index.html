FLAGSHIP PROJECT 2026

Resilient

Autonomous Open-Source AI Coding Agent Leaderboard & Self-Healing Pipeline.

Resilient is an end-to-end multi-agent orchestration pipeline designed to evaluate zero-cost open-source AI models against real-world GitHub issues. It handles candidate issue discovery, dispatches agents in isolated git fork sandboxes, executes automated test suites (`pytest`, `npm`, `cargo`, `go`), computes composite quality scores, and submits verified PRs upstream.

Key Architectural Highlights

  • Multi-model agent retry loop supporting Gemini 2.5, Qwen 2.5 Coder, Groq Llama 3.3, and Ollama.
  • PostgreSQL transaction boundaries guarding terminal status immutability.
  • Authenticated upstream PR submission via GitHub App RS256 JWT tokens.
  • 24-hour rolling rate caps (max 2 PRs per repo, max 10 PRs globally per day).
