# Harshit Sharma — 3D Interactive Portfolio Website

An ultra-modern, high-performance 3D developer portfolio website built with Vanilla CSS, Three.js 3D cosmic particle physics, and an interactive Web Terminal.

🌐 **Live Demo**: [https://harshitthek.github.io/portfolio/](https://harshitthek.github.io/portfolio/)

---

## ⚡ Key Features

- **🌌 Three.js 3D Cosmic Canvas**: Interactive starfield particle physics that rotate and respond to mouse cursor movements.
- **🎲 Floating 3D Perspective Cube**: CSS 3D matrix displaying core technologies (`AI/ML`, `FastAPI`, `React`, `Agents`, `Python`, `Postgres`).
- **💻 Interactive Web Terminal**: Embedded zsh terminal (`harshit@lab:~$`) parsing commands (`help`, `about`, `skills`, `projects`, `resilient`, `contact`, `clear`).
- **🚀 Featured Engineering Showcase**: Deep-dive cards for flagship projects including **Resilient** (Autonomous AI Benchmark).
- **🛠️ Filterable Skills Matrix**: Categorized tech stack filter (*Languages*, *AI & Backend*, *Frontend & 3D*, *DevOps*).
- **📬 Glassmorphic Contact Console**: Direct social links and responsive message form with instant feedback state.

---

## 🛠️ Tech Stack
- **Core**: HTML5, CSS3, Modern JavaScript (ES6+)
- **3D Graphics**: Three.js (r128 WebGL)
- **Styling**: Glassmorphism (`backdrop-filter`), CSS Grid & Flexbox, Custom Dark Palette
- **Typography**: Google Fonts (*Plus Jakarta Sans*, *Fira Code*)

---

## 🚀 Quick Start (Local Run)

```bash
# Clone the repository
git clone https://github.com/harshitthek/portfolio.git

# Navigate to project folder
cd portfolio

# Run a local HTTP server (Python or Node)
python -m http.server 3000
```

Open `http://localhost:3000` in your browser!
